<p align="center"><strong>dsh-dfm — 可制造性检查与报价准备</strong></p>

按工艺给 DFM 清单，列出报价所需资料与成本项。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-dfm

## 工具

- `dfm_checklist`：工艺检查清单
- `quote_prepare`：报价资料与成本项

更多工具：https://deepseekbase.com/zh/tools/
